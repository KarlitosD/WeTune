# Brand

- `icon.svg` — fuente vectorial del logo/icono.
- `icon.png` — export 1280×1280.
- `icon-transparent.png` — export con fondo transparente.

Los assets que consume Expo están en `mobile/assets/` (`icon.png`,
`android-icon-*.png`, `splash.png`, `favicon.png`). Si cambia el logo, regenerar
esos archivos desde esta fuente y actualizar el `backgroundColor` de splash e
iconos adaptativos (`#0f172a`).
